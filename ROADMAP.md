# Roadmap

This roadmap is intentionally outcome-oriented rather than date-oriented. Autonomous agents should revise non-constitutional priorities when evidence shows a better path.

## Phase 0 — Bootstrap the substrate

**Goal:** make autonomous work persistent, auditable, and empirically improvable.

- [x] Public mission and operating model
- [x] Constitutional principles
- [x] Initial world-problem taxonomy
- [x] AI maintainer charter
- [x] Persistent agent state
- [x] Evaluation framework
- [x] Provenance-first evidence schema
- [x] Citation metadata
- [ ] Automated schema validation
- [ ] Broken-link validation
- [ ] Duplicate-entity detection
- [ ] Consequential-claim citation checks
- [ ] Structured changelog / run log

## Phase 1 — Establish the baseline world model

**Goal:** create a sourced, current, machine-readable baseline for every top-level problem category.

For each problem:

- define measurable indicators;
- establish current global baseline values;
- record source dates and uncertainty;
- identify major affected populations;
- map leading causal hypotheses;
- collect important counterevidence;
- identify authoritative datasets;
- map major organizations, research programs, and open-source projects;
- identify intervention families;
- identify unresolved questions;
- document plausible AI contributions and AI-specific risks.

## Phase 2 — Build the knowledge graph

**Goal:** connect problems, evidence, causes, interventions, organizations, projects, datasets, and open questions.

- canonical entity identifiers;
- typed relationships;
- source provenance;
- contradiction representation;
- freshness / last-reviewed metadata;
- confidence with rationale;
- API- and AI-friendly indexes.

## Phase 3 — Prioritization without false objectivity

**Goal:** identify unusually valuable research/action opportunities while preserving normative transparency.

Potential dimensions:

- scale of the constraint;
- severity;
- tractability;
- neglectedness;
- evidence strength;
- reversibility;
- rights / coercion risk;
- uncertainty reduction value;
- cost-effectiveness;
- option-expansion potential;
- dependencies on other problems.

No single ranking should be presented as morally neutral. Alternative weighting schemes should remain inspectable.

## Phase 4 — Autonomous research organization

**Goal:** let AI agents substantially operate the research system.

- specialized scouts;
- evidence reviewers;
- contradiction finders;
- code maintainers;
- source freshness monitors;
- independent auditors;
- benchmarked task-selection agents;
- self-improvement experiments;
- automatic low-risk fixes;
- PR-based major changes.

## Phase 5 — Public coordination layer

**Goal:** become genuinely useful infrastructure for outside humans and AI systems.

- searchable website / API;
- structured project atlas;
- open-question registry;
- machine-readable contribution opportunities;
- periodic evidence-grounded state-of-the-world summaries;
- clear citation paths;
- interoperability with other open knowledge systems;
- contributor workflows for researchers, developers, domain experts, and AI agents.

## Phase 6 — Evidence-backed experiments

**Goal:** move cautiously from mapping problems to helping test solutions.

Experiments should begin small, reversible, measurable, and ethically governed. Real-world execution authority should remain substantially more constrained than research and software-maintenance authority.

## Long-term test

The project is succeeding only if it becomes increasingly useful for answering questions such as:

> What major constraints on human freedom and peaceful cooperation appear most important right now?

> What do we know, what do we disagree about, and what remains uncertain?

> Who is already working on these problems?

> Where could another researcher, developer, organization, funder, policymaker, volunteer, or AI agent contribute something genuinely useful next?
