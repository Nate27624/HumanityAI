**Question:** If HumanityAI has three near-term substantive operator slots to spend across the currently mature P03, P06, and P07 lines, where should those slots go to maximize decision value rather than artifact count?

**Recommendation:**

1. **First slot — P03 / Bangladesh:** build a bounded within-country hypertension delivery comparison centered on medicine continuity, missed-visit recovery, task-sharing, treatment intensification, and cost per eligible/controlled patient where common denominators are available.
2. **Second slot — P06 / Nigeria:** build an input-completeness/resource map for one comparable electricity-access decision, focused on realized service tier, household payment burden, financing/subsidy architecture, uptake/default, reliability, and persistence. Do **not** rank modalities unless these common denominators can be sourced.
3. **Third slot — hold rather than automatically spend on P07:** Benin already supplies a strong long-horizon within-study training/cash comparison with explicit component costs. Spend another P07 slot only when a concrete downstream choice requires a comparable second study, a verified unresolved combined-arm cost, or an implementation/adoption question that could change the package decision.

This is a **compute-allocation ranking, not a ranking of social importance or intervention cost-effectiveness across P03/P06/P07.** The domains use different outcome units, horizons, populations, and cost structures, so their dollar figures must not be compared directly.

## Why P03 gets the first slot

The canonical hypertension gate says the useful question is no longer whether antihypertensive treatment works in aggregate, but which care-cascade bottleneck prevents durable control in a specific system. Bangladesh appears unusually ready for a bounded downstream test because public sources already expose several of the variables the gate requires.

Current source-grounded anchors carried forward from the integrated P03 work and its downstream-use synthesis:

- WHO reports that selected Bangladesh regions improved hypertension control from roughly **15% to 56% between 2019 and 2025**, while national control remains much lower. That implementation heterogeneity is more useful for diagnosis than another global efficacy review.
- WHO documents phased primary-care scale-up with standardized protocols, essential medicines/diagnostics, capacity building, supervision, and digital monitoring.
- The Bangladesh Hypertension Control Initiative reports real-time facility-level control and missed-visit data; overdue-patient follow-up was associated with a fall in three-month missed visits from roughly **50% to 26%** in the implementation program. This is program evidence, not a randomized causal estimate.
- A Bangladesh HEARTS costing study estimated about **US$8.9 per eligible patient per year** in four upazilas, with medicines about **43%** and provider time about **38%** of annual program cost. The same work identifies physician capacity as a scale-up constraint and makes task-sharing economically relevant.

Primary sources already cited in the canonical P03 thread:

- WHO hypertension global update: https://www.who.int/news/item/23-09-2025-uncontrolled-high-blood-pressure-puts-over-a-billion-people-at-risk
- WHO Bangladesh protocol-based care scale-up: https://www.who.int/southeastasia/news/detail/26-06-2023-bangladesh-three-million-with-hypertension-and-diabetes-placed-on-protocol-based-care-by-2025
- Resolve to Save Lives Bangladesh implementation case: https://resolvetosavelives.org/strategies-in-action/bangladesh-better-data-blood-pressure/
- Bangladesh HEARTS costing study: https://pubmed.ncbi.nlm.nih.gov/35760540/

### Named P03 decision

Use one operator slot to test whether 2–4 Bangladesh implementation areas with materially different retention/control performance can be compared on a common control definition and horizon, and whether the observed performance gap is plausibly routed through:

- medicine continuity / stock management;
- overdue-patient tracing and refill interval;
- treatment intensification;
- cadre mix and titration authority;
- provider capacity / compensation;
- patient travel, time, and out-of-pocket burden.

**Kill test:** if facility/program data cannot support a common denominator and horizon, stop after the bottleneck map. Do not fabricate a cost-per-controlled-patient ranking from incompatible program summaries.

### Decision delta

A successful P03 slot could directly change **which delivery lever HumanityAI studies next** inside a mature intervention class. The source set already contains a cost anchor, observable retention/control variation, and implementation variables, so the expected information value per slot is comparatively high.

## Why P06 gets the second slot

The canonical electricity-access gate is also mature enough to move downstream: service tier, affordability, financing, reliability, and persistence must be specified before comparing modalities. Nigeria has a plausible public implementation base, but the denominator problem is less resolved than in Bangladesh.

Current source-grounded anchors from the integrated P06 work and downstream-use synthesis:

- World Bank reporting on Nigeria's NEP/DARES programs provides public geospatial planning, cost-benchmarking, results-based financing, mini-grid, and solar-home-system deployment information.
- By December 2024, NEP reporting cited **more than 5.9 million people reached**, **180 commissioned mini-grids**, and **more than 1 million solar-home-system units**; DARES targets **17.5 million** people with new or improved electricity access.
- The canonical P06 gate already establishes that connection count is not a common outcome denominator and that service tier, household affordability, financing cost, subsidy design, reliability, and persistence must be observed rather than inferred from technology labels.

Sources already cited in the P06 downstream-use synthesis:

- Nigeria NEP implementation/results document: https://documents1.worldbank.org/curated/en/099123024214039631/pdf/P161885-bc5f2bca-9f95-4934-8e58-4c8592e0b7b4.pdf
- World Bank Nigeria mini-grid market feature: https://www.worldbank.org/en/news/feature/2025/03/07/expanding-nigeria-s-mini-grid-market

### Named P06 decision

Use one operator slot to determine whether a **single Nigeria pathway comparison** can be specified with a common realized service tier and enough public data to compare no more than two financing-and-technology packages on:

- household tariff/payment burden;
- subsidy/grant structure and financing cost;
- uptake after offer/connection;
- default, disconnection, or continued payment where available;
- reliability/service availability;
- persistence after project support;
- productive-use or other clearly specified downstream outcome.

The output should be an **input-completeness map** first. A modality ranking is permitted only if the common denominators actually exist.

**Kill test:** if tariff/payment-burden, persistence, and comparable service-tier data are not recoverable, stop with a documented value-of-information gap. Do not divide sector investment by people reached or compare cost per connection across unlike service tiers.

### Decision delta

A successful P06 slot could tell the controller whether Nigeria is ready for a real package comparison or whether the next marginal unit of compute should move elsewhere. That is useful, but the current public data appear less obviously complete on household payment burden and persistence than the Bangladesh P03 funnel data, so P06 ranks second.

## Why P07 should be held unless a concrete choice emerges

The integrated Benin note already supplies unusually strong within-study information:

- randomized training-only, cash-only, training+cash, and control arms;
- roughly **45 months after training / 38 months after grant** at the longest follow-up;
- sustained training-only business/earnings gains in the study population;
- no primary revenue/profit/earnings effect from grant-only at the longest follow-up, while some welfare/asset effects remain;
- reported component delivery costs of about **US$1,050 per training beneficiary** and **US$629 per cash-grant beneficiary**;
- the report's simple earnings-payback calculation of about **36 months for men** and **64 months for women**, with the women's figure depending on persistence beyond observed follow-up;
- explicit uncertainty about whether combined-arm costs are additive and about portability outside this specific program/population.

Canonical primary sources:

- World Bank / Government of Benin final evaluation report: https://documents1.worldbank.org/curated/en/099005006302210770/pdf/P1477800853c6e050ba2403b0a1ba2239d.pdf
- World Bank microdata study description: https://microdata.worldbank.org/catalog/4044/study-description

### Named P07 decision

**Do not spend a slot merely to find another training-versus-cash estimate.** The next P07 slot should require one of these downstream questions:

1. a program designer is choosing between a Benin-like skill/management package and capital support for a sufficiently comparable target population;
2. a second study can materially test whether the Benin long-horizon pattern transports under different implementation quality, gender constraints, baseline skills, or grant design;
3. an unresolved cost/accounting input would change a package decision rather than only improve documentation.

**Kill test:** if no concrete package/adoption/resource decision can be named, hold P07 compute. The marginal value of another generic ALMP evidence product is lower than converting P03/P06 gates into actual decision inputs.

## Important non-comparability warning

The cost anchors above are **not commensurate**:

- P03 reports annual health-program cost per eligible patient in a specific implementation setting;
- P06 includes infrastructure/financing programs with service-tier and asset-lifetime issues;
- P07 reports per-beneficiary intervention component costs plus a simple earnings-payback calculation.

Do not divide, normalize, or scalar-rank these dollar values across domains without a common welfare framework, horizon, population, counterfactual, and cost perspective. This document ranks **the expected value of the next research/decision slot**, not the interventions themselves.

### Value-of-information rule

A domain should receive another slot only when the expected output can change at least one of:

- package choice;
- implementation lever;
- ranking among plausible next actions;
- confidence enough to change allocation;
- whether a comparison should be attempted at all.

If the likely output is only another literature summary consistent with an already-canonical routing gate, the slot should move elsewhere.
