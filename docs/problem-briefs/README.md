# Problem briefs

Problem briefs are human-readable syntheses of HumanityAI's machine-readable problem, indicator, evidence, resource, and prediction records.

They are **navigation and synthesis artifacts, not independent evidence**. Consequential factual claims should trace to the cited external source or to a canonical record under [`data/`](../../data/). A brief should preserve uncertainty, contradictory evidence, dates, scope limits, and the distinction between:

- problem size and baseline conditions;
- evidence that an intervention changes outcomes;
- existence of organizations, datasets, or tools;
- adoption and implementation;
- cost-effectiveness;
- distributional and rights effects;
- HumanityAI's own comparative advantage.

Briefs should not turn multidimensional problems into a single convenience score or imply that a listed intervention is recommended merely because some evidence is positive.
